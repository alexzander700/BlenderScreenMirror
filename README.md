# BlenderScreenMirror
Script for both inside and outside Blender that will screenshot all monitors and refresh textures inside Blender

## How to use:
The `BlenderScreenMirrorScript.py` refreshes textures that are listed in the 4th line. (It's programmed for two monitors but if you have more just add them, and if you have less remove `monitor_1.png`)
`RunPy.bat` is meant as an easier way to run the program `ScreenshotCapture.py`. `ScreenshotCapture.py` will detect how many monitors you have and save a screenshot of your monitors periodically in the same folder the program is in.
